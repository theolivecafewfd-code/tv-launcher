# Player design companions

Start with [PLAYER_DESIGN.md](../PLAYER_DESIGN.md), the authoritative draft specification.

| File | Purpose |
| --- | --- |
| [references/glass.html](references/glass.html) | Preferred glass concept, packaged for local/offline viewing |
| [references/clean-v1.html](references/clean-v1.html) | Preserved Clean V1 concept |
| [tokens.json](tokens.json) | Proposed native token values; manually translate into Compose |
| [ACCEPTANCE.md](ACCEPTANCE.md) | Per-stage implementation and hardware check record |

The HTML bodies preserve the earlier concepts. A document wrapper, explanatory banner and local icon adapter make them usable outside the chat. Browser interactions and concept-only features do not define the app's functional scope.

Keep this directory beside `docs/PLAYER_DESIGN.md`. No external fonts, provider credentials, streams or remote JavaScript are required by these reference pages.

Version 0.1 is a review draft. Do not infer implementation approval from the presence of these files.
